    tdfpy.MetaData dataclass ¶

    MetaData(table: Mapping[str, MetaValue])

    Bases: _KeyTable

    The GlobalMetadata table as a read-only mapping of key to value.

    A missing key raises :class:~tdfpy.TdfpyKeyError, from indexing and from the typed properties below.

MzAcqRangeUpper             1700.000000
